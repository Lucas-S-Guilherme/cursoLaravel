## 🚀 Tecnologias Utilizadas

* **PHP 8.x**
* **Laravel 11/12**
* **Banco de Dados:** MySQL/PostgreSQL
* **Ambiente:** Ubuntu 24.04 (Linux) com Docker

## 📚 Tópicos de Estudo

- [x] Instalação e Configuração
- [ ] Rotas, Controllers e Views
- [ ] Blade Engine
- [ ] Eloquent ORM e Migrations
- [ ] Autenticação e Middlewares
- [ ] Integração com Vue.js / JavaScript

## 🛠️ Como rodar este projeto

1. Clone o repositório:
   ```bash
   git clone [https://github.com/Lucas-S-Guilherme/cursoLaravel.git](https://github.com/Lucas-S-Guilherme/cursoLaravel.git)

   Instale as dependências:
    Bash

    composer install
    npm install

    Configure o ambiente:
    Bash

    cp .env.example .env
    php artisan key:generate

    Suba os containers ou servidor:
    Bash

    php artisan serve
